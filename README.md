## 📖 Sobre o projeto

Este projeto foi desenvolvido como desafio final do bootcamp da **DIO (Digital Innovation One)**.

A proposta do projeto é desenvolver uma API inteligente capaz de receber comandos por voz, convertê-los em texto e gerar respostas utilizando Inteligência Artificial.

O objetivo principal foi praticar a integração entre **Spring Boot**, APIs externas e recursos de reconhecimento de fala, aplicando conceitos de desenvolvimento back-end em uma aplicação real.

## ▶️ Como executar

### Pré-requisitos

* Java 25
* Gradle
* Chave de API compatível com o serviço de IA utilizado

### Clonando o projeto

```bash
git clone https://github.com/sarahrbz/Projeto-Final-DIO-API-inteligente-com-reconhecimento-de-fala-e-Spring-Boot.git
```

### Executando

* No Windows:
```bash
gradlew bootRun
```
* No Linux/macOS:
```bash
./gradlew bootRun
```

## 📝 Observações

Este projeto foi desenvolvido como parte do desafio final da DIO.

Devido ao limite de créditos da API de Inteligência Artificial utilizada durante o desenvolvimento, não foi possível realizar testes completos da integração. 
Entretanto, toda a estrutura da aplicação foi implementada e o projeto permanece disponível como demonstração dos conhecimentos adquiridos durante o bootcamp.
